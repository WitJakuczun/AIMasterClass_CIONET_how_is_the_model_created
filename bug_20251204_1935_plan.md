# Plan for Fixing Matplotlib Threading Issue

## Context
The application crashes with `NSInternalInconsistencyException` when generating plots via the chat interface because Matplotlib attempts to create a GUI window on a background thread. This is a known issue on macOS when using standard Matplotlib backends outside the main thread.

## Goal
Configure Matplotlib to use the non-interactive 'Agg' backend, which allows plot generation to files without requiring a window or the main thread.

## Phase 1: Reproduction
- [x] Create `reproduce_thread_issue.py` to simulate the crash by running `plot_model_comparison` (or a simplified plotting function) in a background thread.
- [x] Run the reproduction script to confirm the crash.

## Phase 2: Fix Implementation
- [x] Modify `mlops/visualization.py` to force the 'Agg' backend.
    - Ensure `matplotlib` is imported.
    - Set `matplotlib.use('Agg')` before `pyplot` is imported or used to prevent GUI backend initialization.

## Phase 3: Verification
- [x] Run `reproduce_thread_issue.py` again to verify the fix (should pass without error).
