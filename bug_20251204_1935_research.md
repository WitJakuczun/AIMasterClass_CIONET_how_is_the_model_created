## Research: `NSWindow should only be instantiated on the main thread!` error in `visualize_comparison`

**Summary**
The error "NSWindow should only be instantiated on the main thread!" occurs when the `visualize_comparison` function attempts to generate a Matplotlib plot. This is due to Matplotlib trying to create a GUI window on a thread that is not the main thread, which is a common restriction for GUI toolkits on macOS.

**Detailed Findings**
- **`bug_20251204_1935.md`**: This file documents the bug, showing the traceback originating from a call to `visualize_comparison` within a `chatml` context. The key error message is `*** Terminating app due to uncaught exception 'NSInternalInconsistencyException', reason: 'NSWindow should only be instantiated on the main thread!'`.
- **`mlops/app.py`**:
    - The `Application` class contains the `visualize_comparison` method.
    - This method is responsible for gathering experiment results and then calling `plot_model_comparison` to generate a visualization.
    - The `visualize_comparison` method itself does not explicitly handle threading, suggesting it's being called from an environment that is already off the main thread.
- **`mlops/visualization.py`**:
    - This file contains the `plot_model_comparison` function, which is directly responsible for creating the Matplotlib plot.
    - Line 39: `plt.figure(figsize=(10, 6))` is the exact line that attempts to create a new Matplotlib figure. This action, when performed on a non-main thread on macOS, triggers the `NSWindow` error.

**Architecture & Patterns**
The observed pattern is a common pitfall when integrating GUI-dependent libraries like Matplotlib into multi-threaded or event-driven applications, especially on platforms with strict GUI threading models like macOS. The `chatml` environment likely dispatches function calls to a separate thread for execution, leading to the conflict with Matplotlib's requirement to operate on the main thread for GUI operations.

**Conclusion**
The bug is caused by Matplotlib's attempt to create a GUI window on a non-main thread when `visualize_comparison` is invoked through the `chatml` system. This is a threading incompatibility issue specific to how Matplotlib interacts with the underlying GUI framework on macOS.
